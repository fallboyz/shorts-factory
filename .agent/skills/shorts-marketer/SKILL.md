# 📺 YouTube Shorts Marketer Skill

이 스킬은 제작된 쇼츠 영상이 유튜브 알고리즘의 선택을 받을 수 있도록 최적화된 메타데이터(제목, 설명, 태그)를 생성하고, 사용자가 즉시 복사하여 사용할 수 있는 형식으로 가공하는 가이드입니다.

## 🎯 핵심 전략

1. **주제 정제 (Topic Cleaning)**:
   - 주제명 앞의 숫자와 언더바(예: `01_`, `02_`)를 완벽히 제거하여 순수한 키워드만 추출합니다.

2. **제목 (Title)**: 
   - 시각적 주목도를 높이기 위한 **후킹 문구**를 최우선으로 배치합니다.
   - 클릭을 유도하는 자극적인 질문이나 반전을 포함합니다. (예: "당신만 몰랐던...", "충격적인 실체")

3. **설명 (Description)**:
   - **인간 친화적 줄바꿈**: JSON 이스케이프 문자(`\n`) 대신 실제 줄바꿈을 사용하여 메모장에서 즉시 긁어 쓸 수 있게 합니다.
   - **풍부한 해시태그**: `#Shorts`, `#쇼츠`를 포함하여 **최소 8개 이상**의 연관 해시태그를 본문에 배치합니다.

4. **검색 최적화 태그 (Suggested Tags)**:
   - 유튜브 업로드 시 하단 '태그' 칸에 쉼표로 구분하여 일괄 입력할 수 있는 키워드 세트를 제공합니다.
   - 검색 빈도가 높은 연관 검색어를 전략적으로 포함합니다.

## 🚀 워크플로우

1. **주제 정제**: 입력받은 `topic` 변수에서 불필요한 숫자와 특수문자를 제거합니다.
2. **대본 분석**: 최종 대본 내용을 읽고 가장 임팩트 있는 핵심 키워드를 파악합니다.
3. **메타데이터 패킹 (TXT 기반)**:
   - 사용자가 복사하기 편하도록 `[유튜브 쇼츠 제목]`, `[영상 설명란]`, `[유튜브 태그 (복사용)]` 섹션으로 나눕니다.
4. **저장**: `data/metadata/{id}_{topic}.txt` 형식으로 저장합니다.

## 💡 생성 예시 (TXT 포맷)

```text
[유튜브 쇼츠 제목]
아직도 정체를 모르는 기괴한 소리, 타오스 험의 진실 �

[영상 설명란]
전 세계를 공포에 빠뜨린 의문의 소음 타오스 험!
이 소리를 직접 듣는다면 여러분은 어떤 기분일까요?

구독하고 더 많은 우주의 비밀을 만나보세요! ✨

#Shorts #쇼츠 #타오스험 #미스터리 #공포 #지식쇼츠 #소름 #미해결사건

[유튜브 태그 (복사용)]
타오스 험 원인, 타오스 험 소리, 미스터리, 기괴한 사건, 세계 괴담, 공포 실화, 과학 미스터리, 설명 불가능, 무서운 이야기, 지식
```
